# Проверка работоспособности

> История ранних проверок. Актуальный итог: 76 инструментов и 56 unit-тестов;
> последние полные живые прогоны перечислены в [COVERAGE.md](COVERAGE.md)
> и [STABILITY.md](STABILITY.md). Числа и ограничения ниже относятся к ранним версиям.

Проверено 2026-10-01 на Windows, Python 3.13.15,
КОМПАС-3D v25 Учебная версия, MCP Python SDK 1.30.0.

## Результаты

- `python -m unittest discover -s tests -p "test_*.py" -v`: 9 тестов, OK.
- `python tests/smoke_mcp.py`: успешный MCP initialize и каталог 15 инструментов;
  19 вызовов, включая ожидаемые ошибки отрицательного радиуса и перезаписи файла.
- Реальная геометрия: отрезки прямоугольника, окружность, дуга, ломаная, текст.
- Проверены переключение слоя, создание/удаление отрезка, выполнение Python.
- Созданы и повторно открыты FRW, экспортирован DXF; PNG просмотрен — на нём
  окно КОМПАС с построенной геометрией, не окно OpenCode и не чёрный кадр.
- `opencode.cmd mcp list`: `kompas connected`.
- Вызов `kompas.status` непосредственно из OpenCode успешно вернул активный
  документ и список документов КОМПАС.

## Добавленная поддержка 3D

- Модульные тесты: 16, OK (`test_backend.py` + `test_3d.py`).
- `tests/smoke_3d.py`: пройдены проверки через отдельный MCP stdio-процесс;
  в каталоге теперь 20 инструментов.
- Основание 100×50×12 мм: габариты `[0,0,0,100,50,12]`, объём 60000 мм³.
- Вырез Ø10 на глубину 12 мм: объём 59057.52220392306 мм³, совпадает
  с `60000 - pi*5^2*12` в пределах допуска 1e-7.
- Вырез без пересечения тела возвращает ошибку; объём модели остаётся прежним.
- Цилиндр с обратным выдавливанием: нижняя Z=-20, верхняя Z=0;
  обратный вырез Ø4 также проверен по расчётному объёму.
- Треугольные профили на XZ и YZ: объём призмы 2000 мм³.
- M3D сохранён и переоткрыт, объём сохраняется; старый ID эскиза отклоняется.
- PNG первой успешной 3D-проверки просмотрен: на нём реальная деталь с отверстием.
- Повторный `tests/smoke_mcp.py` подтвердил отсутствие регрессии 2D.
- Сервер `kompas` переподключён в OpenCode, новые инструменты доступны;
  `model_info` вызван из этой сессии на сохранённой детали и подтвердил объём.

Последние 3D-артефакты: `artifacts/3d-20261001-171959-180348/`:
`plate.m3d`, `reverse-cylinder.m3d`, `plate.png`, `report.json`.
2D-регрессия: `artifacts/smoke-20261001-171731-063351/`.
